Setup Guide

Quick start: enable the provider(s) you use, pick visible groups, then fine-tune with Sensor Selection and Overlay Settings.

1) Choose your sensor provider(s)

  • SiR reads sensors from shared memory providers: RTSS/MSI, AIDA64, and HWiNFO/LHM.
  • In Settings → Data Sources → Shared Memory Sources, keep only the providers you actually use enabled.
  • Provider apps must be running while SiR is open.

2) Provider setup details

  • AIDA64: File → Preferences → External Applications → enable Shared Memory.
  • HWiNFO/LHM: enable shared-memory sensor output in their settings.
  • RTSS/MSI: best for live FPS and Frame Time telemetry.

3) Build your layout in SiR

  • Use Visible Sensors to show/hide whole groups (FPS, CPU, GPU, Memory, PSU, Fans, Network, Drives, Other).
  • Use Sensor Selection for per-sensor visibility, overlay inclusion, and drag-to-reorder.
  • Use Summary Mode for a compact overall snapshot.

4) Overlay setup

  • Enable overlay in Appearance → On-Screen Overlay.
  • Configure style, position, monitor, font size slider, spacing, unit scale, colors, and background opacity.
  • Set a global Toggle Hotkey to quickly show/hide overlay in game or desktop use.

5) Web Monitor and sharing

  • Enable Web Monitor in Connectivity, then apply host/port settings.
  • Use 127.0.0.1 for local-only access. Use 0.0.0.0 to listen on all interfaces (LAN), and note this can also allow WAN/public access if firewall rules, router port forwarding, or cloud/public networking expose the port.
  • Open the provided URL from another device on the same network if LAN sharing is enabled.

6) If sensors are missing, stale, or frozen

  • Confirm the right provider toggle is enabled in SiR.
  • Re-check provider shared-memory options and restart the provider app.
  • For FPS/Frame Time issues, verify RTSS/MSI is running and actively updating.
  • If needed, restart SiR after provider configuration changes.
